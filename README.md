# Meteostanice – Android widget

Widget pro meteostanici **Sencor SWS 16600 WiFi** (přes Tuya Cloud) s předpovědí na 10 dní.

- **Velký widget** – roztahovací, podle velikosti ukáže základ, všechna data ze stanice, nebo i předpověď.
- **Malý widget 2×1** – teplota a vlhkost jednoho zvoleného kanálu (přenastavení dlouhým stiskem).
- **Předpověď** – Open-Meteo (zdarma) nebo Google Weather API (vlastní klíč).
- **Aktualizace** – aplikace sama najde novou verzi v Releases a nabídne instalaci.

## Stažení
Poslední APK je v [Releases](../../releases/latest). Každý push do `main` sestaví a vydá novou verzi.

## Nastavení
V aplikaci zadej Access ID, Access Secret a Device ID z [iot.tuya.com](https://iot.tuya.com)
(Cloud projekt, datové centrum Central Europe, propojený účet aplikace Tuya).
Klíče se ukládají jen v telefonu, v repozitáři nejsou.
